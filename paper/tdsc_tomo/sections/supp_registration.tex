This table is the ``per-experiment registration timing in full'' the main
paper's Data Availability statement and Section~\ref{sec:limits} point to.
Times are UTC, read from frozen file mtimes and commit author dates; the
registration-header dates are author-local (UTC+2) and are noted only where
they disagree with the frozen record. Offsets are measured from the first
data write of the same experiment.

\noindent The verdict-channel and transcript-audit records, the canned-turn
decomposition (591 turns across E2-v1, E29, E30 Flash/Pro; E31 adds 83;
E30 MiniMax adds 305; 979 in total), and the per-panel censoring counters are
in the claims--evidence ledger, which pins every row above to an artifact
path and commit.
